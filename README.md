# Global E-Commerce Sales Dashboard

An interactive and visually engaging **Power BI Dashboard** designed to analyze and monitor global e-commerce sales performance. This dashboard provides insights into sales, profit, customer segments, payment methods, product categories, shipping costs, and regional performance.

---


## 🚀 Features

- **Sales Overview KPIs**
  - Total Sales
  - Total Revenue
  - Total Profit
  - Profit Margin %
  - Average Order Value
  - Average Profit Per Order

- **Customer Insights**
  - Profit by Customer Segment
  - Consumer vs Corporate vs Home Office analysis

- **Payment Method Analysis**
  - Total Sales by Payment Method
  - Shipping Cost Distribution

- **Product Category Performance**
  - Profit contribution by category
  - Category-wise comparison

- **Geographical Insights**
  - Total Sales by Country (Map Visualization)
  - Regional Sales Trends

- **Interactive Visualizations**
  - Bar Charts
  - Donut Charts
  - Funnel Chart
  - Line Chart
  - Map Visuals
